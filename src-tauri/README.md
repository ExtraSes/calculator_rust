# Калькулятор с сохранением результатов

## Описание

Этот калькулятор автоматически сохраняет все вычисления в файл `calculations.txt` при нажатии кнопки "=".

## Запуск

1. Убедитесь, что у вас установлен Rust и Tauri
2. Перейдите в папку `src-tauri`
3. Запустите приложение:

```bash
cargo tauri dev
```

## Функциональность

- **Ввод цифр**: Нажмите на цифры для ввода чисел
- **Операции**: Используйте кнопки +, -, *, / для выбора операции
- **Вычисление**: Нажмите = для выполнения вычисления
- **Очистка**: Нажмите C для сброса калькулятора

## Автоматическое сохранение

При каждом вычислении (нажатие кнопки "=") результат автоматически сохраняется в файл `calculations.txt` в формате:
```
2.0 + 3.0 = 5.0
10.0 * 2.0 = 20.0
```

## Файлы

- `calculations.txt` - файл с историей вычислений
- `src/simple_calculator.rs` - основная логика калькулятора
- `src/main.rs` - точка входа приложения

## Установка MySQL (опционально)

Если вы хотите использовать базу данных MariaDB вместо файлового сохранения, следуйте инструкциям в `MYSQL_SETUP_WINDOWS.md`.
